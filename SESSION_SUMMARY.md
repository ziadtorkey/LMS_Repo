## Decisions made
- **MySQL provider:** Oracle `MySql.EntityFrameworkCore` (Pomelo has no EF Core 10 release; `docs/adr/0001-mysql-provider.md`). Each migration touching `OrgUnitPath` columns is hand-fixed to `varchar(400) CHARACTER SET ascii COLLATE ascii_general_ci`.
- **Isolation:** one generic query filter per entity; malformed scope path matches nothing; platform admin bypasses tenant and scope, never soft delete. `IgnoreQueryFilters` needs a `// ISOLATION-BYPASS: reason` marker, re-applied `OrganizationId` and `!IsDeleted`, and an allow-list entry (`BranchMaterializer.cs` now also uses it for live course codes).
- **Unit-targeted endpoints** use `CheckUnitAsync` (invisible unit is 404, never 403). Relationship scoping (Supervisor → supervised courses, Teacher → own class courses) goes through `IRelationshipScope`; outside the filter is 404.
- **Live keys:** nullable `*Key` columns cleared on soft delete (`ILiveKeyed`) replace partial unique indexes. Course codes are upper-cased and unique per client among live courses.
- **Course ownership (Q1):** owner is the client root or a unit with `IsCourseManagementLevel`, else 400 `invalid_owner_unit`. **Allocation:** course Active and owned at or above the unit (400 `course_not_available`); duplicate 409 `allocation_exists`; removal 409 `allocation_in_use` unless another allocation covers the classes; all or nothing.
- **Restrictions (D39):** only Religion, Gender, LevelType; AND across types, any-of within a type; changing them keeps existing enrollments.
- **Exceptional enrollment (D40):** supervisors decide; a course with none is decided by Managers/Org Admins at or above the class; Counselors, Managers and Org Admins may request.
- **Copy/template courses:** the materializer applies `transformName`/`transformCode` to course names and codes, so copy suffixes work. Template placeholder map values must be exactly one token, e.g. `{CodeX}`. Course skips reuse the existing skipped list because `CopyBranchResultDto` is a Lead-owned contract.
- **Import framework choices:** `ImportCommitContext.AfterCommit` list instead of `IInvitationOutbox`; `ImportService.UploadAsync` takes an already-checked `OrgUnit`; jobs carry `[Queue("imports")]` and the Hangfire server uses `JobQueues.All`; stuck `Committing` batches fail after 2 hours. `ImportTestHost` registers the real `PolicyEvaluator`; the default test host uses a stub that does not model policy blocks.
- **Rejected or avoided:** no force-pushes; no workaround for the denied `gh pr ready`.
